# 🦔 Колючий забег (Hedgehog Dash)

Аркадная игра-лабиринт в духе Pac-Man с лесным характером: ёж собирает яблоки
в ночном саду, а семья лис выходит на охоту. Съешь золотую грушу — свернись
в клубок и сам тарань лисов!

Вся игра — **один файл `index.html`** без единой внешней зависимости:
графика рисуется кодом на Canvas, звук синтезируется Web Audio API.
Проект разработан итеративно, в партнёрстве с LLM, по методологии
single-file разработки для Android WebView.

---

## ✨ Особенности

- **Механика Pac-Man с лесным лицом**: яблоки, золотые груши (режим клубка), туннели-бревна.
- **4 лиса с разными ИИ-характерами**:
  -  Рыжик — преследует в лоб;
  - 🦊 Соня — заходит наперерез;
  - 🦊 Тихоня — хитрит с фланговым заходом;
  - 🦊 Фомка — трусит и держится подальше.
- **Режим клубка**: груша превращает ежа в шар — лисы пугаются и выбиваются с комбо ×2.
- **Бесконечные уровни**: со 2-го уровня лабиринт генерируется процедурно
  (симметрия, гарантированная связность, петли вместо тупиков, растущая плотность).
- **Галерея образов**: пронумерованные скины ежа, каждого лиса, яблок, груш,
  изгородей и фонов — меняются прямо в игре.
- **Реалистичные процедурные модели**: градиенты шерсти, слои иголок,
  анимация бега, тени.
- **Сочность**: частицы, тряска экрана, всплывающие очки комбо.
- **Чиптюн-музыка** и эффекты, синтезированные на Web Audio (темы меню и игры).
- **Удобное управление**: свайпы по всему экрану, буфер ввода 0.7 с,
  мгновенный разворот; на десктопе — стрелки/WASD.
- **Адаптивность**: чёткий рендеринг на любом экране с учётом devicePixelRatio.

## 🕹️ Управление

| Действие | Сенсор | Клавиатура |
|---|---|---|
| Движение | свайп | стрелки / WASD |
| Пауза | тап | P / Escape |
| Галерея скинов | кнопка «СКИНЫ» | C |
| Листать варианты | тап по стрелкам | ← / → |
| Сменить категорию | тап по вкладке | ↑ / ↓ |

## 🛠️ Технологии

- Один файл `index.html`, один тег `<script>` — полная автономность.
- **Canvas 2D** — вся графика процедурная (спрайты, градиенты, частицы).
- **Web Audio API** — синтез музыки и эффектов без аудиофайлов.
- **requestAnimationFrame + delta time** — плавность на любом железе.
- **Паттерн State** — Menu / Gallery / Play / Pause / GameOver.
- Целевая платформа — **Android WebView** (сенсорное управление, слабые устройства).
