# EJrun
🦔 Аркада в которой ёж собирает яблоки в лабиринте из изгородей и убегает от семьи лис. Однофайловая HTML5-игра (Canvas + Web Audio) без внешних зависимостей: процедурные уровни, ИИ-характеры лис, режим клубка, галерея скинов, чиптюн-музыка. Оптимизирована под сенсорное управление и Android WebView.
